# AdOrder — реклама на витрине (заявка → апрув → оплата → баннер)

Дата: 2026-09-21  
Статус: approved for implementation

## Goal

Платный баннер на главной: залогиненный пользователь подаёт заявку, админ модерирует и фиксирует цену, клиент оплачивает (с промокодом), после webhook публикуется `PromoBanner` на N дней с момента оплаты.

## Decisions

- Отдельная сущность `AdOrder`, UI — вкладка в `/admin/banners` («Витрина» / «Заявки»).
- Единый тариф: `ads_price_per_day`; форма считает `дни × ставка` (− витринная скидка scope `ads`).
- Пресеты 3/7/14/28 только выбирают срок; «Свой срок» 1–90.
- Только авторизованные.
- Статусы (русские строки в БД): `новая` → `одобрена` → `опубликована` | `отклонена` | `отменена`.
- На апруве админ может править итоговую цену; после `одобрена` поля заявки заморожены.
- Оплата: `kind=ads` в существующем checkout; fulfill создаёт PromoBanner.
- Старые `ServiceOrder` ads не удаляем, новый флоу идёт через AdOrder; публичная форма пишет в AdOrder.

## Non-goals

- Оплата гостями
- Редактирование креатива после апрува
- Отдельный эквайринг
