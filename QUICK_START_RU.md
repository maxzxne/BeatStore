## 📋 Пошаговая инструкция

### Шаг 1: Регистрация и покупка VPS (5 минут)

1. Зайдите на [timeweb.cloud](https://timeweb.cloud)
2. Зарегистрируйтесь (можно через соцсети)
3. Перейдите в раздел **"Облачные серверы"** → **"Создать сервер"**
4. Выберите тариф: **"Оптимальный"** (500₽/месяц) - **рекомендуется для старта**
   - CPU: 2 ядра
   - RAM: 2 GB
   - SSD: 20 GB (можно увеличить позже)
   - **Почему этот тариф:** Достаточно для начала, легко масштабировать
5. Выберите ОС: **Ubuntu 22.04 LTS**
6. Выберите регион: **Москва** или **Санкт-Петербург**
7. Оплатите тариф (картой, СБП или электронными кошельками)

> **📊 Нужна помощь с выбором?** См. [SERVER_REQUIREMENTS.md](./SERVER_REQUIREMENTS.md) - подробные рекомендации по характеристикам сервера

### Шаг 2: Подключение к серверу (2 минуты)

1. В панели управления найдите ваш сервер
2. Скопируйте **IP-адрес** сервера
3. Скопируйте **пароль** для root пользователя (или создайте SSH ключ)

**На Windows используйте:**
- **PuTTY** (скачать: https://www.putty.org/)
- Или встроенный **PowerShell SSH** (Windows 10+)

**Подключение через PowerShell:**
```powershell
ssh root@ваш-ip-адрес
# Введите пароль когда попросит
```

### Шаг 3: Первоначальная настройка сервера (5 минут)

После подключения к серверу выполните:

```bash
# Скачайте скрипт настройки
wget https://raw.githubusercontent.com/ваш-репозиторий/XWinner.beats.please/main/setup_server.sh

# Или создайте файл вручную:
nano setup_server.sh
# Скопируйте содержимое из файла setup_server.sh проекта

# Сделайте исполняемым и запустите
chmod +x setup_server.sh
sudo ./setup_server.sh
```

**Что делает скрипт:**
- ✅ Устанавливает Docker и Docker Compose
- ✅ Настраивает файрвол
- ✅ Устанавливает необходимые пакеты
- ✅ Оптимизирует систему

**После выполнения:** Перезайдите в систему (выйдите и войдите снова)

### Шаг 4: Загрузка проекта (5 минут)

**Вариант А: Через Git (рекомендуется)**
```bash
# Установите Git (если еще не установлен)
sudo apt install git -y

# Клонируйте ваш репозиторий
cd /opt/XWinner.beats.please
git clone https://github.com/ваш-username/XWinner.beats.please.git
cd XWinner.beats.please
```

**Вариант Б: Через SFTP (FileZilla, WinSCP)**
1. Установите [FileZilla](https://filezilla-project.org/)
2. Подключитесь к серверу:
   - Хост: ваш-ip-адрес
   - Пользователь: root
   - Пароль: ваш-пароль
   - Порт: 22
3. Загрузите всю папку XWinner.beats.please в `/opt/XWinner.beats.please/`

### Шаг 5: Настройка переменных окружения (3 минуты)

```bash
cd /opt/XWinner.beats.please/XWinner.beats.please

# Скопируйте пример файла
cp env.example .env

# Отредактируйте файл
nano .env
```

**Обязательно измените:**
```env
# Сгенерируйте случайный ключ (выполните на сервере):
# openssl rand -hex 32
JWT_SECRET_KEY=ваш-случайный-ключ-здесь

# Укажите ваш домен или IP
FRONTEND_URL=http://ваш-ip-адрес:3000
VITE_API_URL=http://ваш-ip-адрес:8000

# Настройка Telegram бота (опционально, но рекомендуется)
# 1. Получите токен у @BotFather в Telegram
# 2. Создайте бота командой /newbot
# 3. Скопируйте токен сюда:
TELEGRAM_BOT_TOKEN=ваш-токен-от-BotFather
TELEGRAM_BOT_USERNAME=ваш-username-бота
# 4. После настройки домена укажите URL вашего сайта:
MINI_APP_URL=https://ваш-домен.ru
```

**Сохраните:** `Ctrl+O`, затем `Enter`, затем `Ctrl+X`

### Шаг 6: Запуск проекта (2 минуты)

```bash
# Сделайте скрипт развертывания исполняемым
chmod +x deploy.sh

# Запустите развертывание
./deploy.sh
```

**Или вручную:**
```bash
# Сборка и запуск
docker-compose up -d --build

# Проверка статуса
docker-compose ps

# Просмотр логов
docker-compose logs -f
```

### Шаг 7: Проверка работы (1 минута)

Откройте в браузере:
- **Frontend**: `http://ваш-ip-адрес:3000`
- **Backend API**: `http://ваш-ip-адрес:8000`
- **API Docs**: `http://ваш-ip-адрес:8000/docs`

## 🤖 Настройка Telegram бота (опционально)

**Бот уже интегрирован и будет работать автоматически!** Просто настройте переменные окружения:

1. **Получите токен бота:**
   - Откройте Telegram и найдите [@BotFather](https://t.me/BotFather)
   - Отправьте команду `/newbot`
   - Следуйте инструкциям и создайте бота
   - Скопируйте токен (выглядит как `123456789:ABCdefGHIjklMNOpqrsTUVwxyz`)

2. **Добавьте токен в `.env` файл:**
   ```bash
   nano .env
   # Добавьте:
   TELEGRAM_BOT_TOKEN=ваш-токен-здесь
   TELEGRAM_BOT_USERNAME=ваш-username-бота
   ```

3. **Настройте Mini App URL (после настройки домена):**
   - В `.env` добавьте: `MINI_APP_URL=https://ваш-домен.ru`
   - В BotFather выполните: `/setmenubutton`
   - Выберите вашего бота
   - Отправьте URL вашего сайта

4. **Перезапустите контейнеры:**
   ```bash
   docker-compose restart backend
   ```

**Бот будет работать автоматически** - он запускается вместе с backend в фоновом режиме!

## 🌐 Настройка домена (опционально)

1. Купите домен (можно на том же Timeweb)
2. В настройках DNS добавьте A-запись:
   - Имя: `@` или `www`
   - Значение: IP-адрес вашего сервера
3. Подождите 5-30 минут для распространения DNS
4. Обновите `.env` файл с новым доменом

## ❓ Решение проблем

### Проект не запускается
```bash
# Проверьте логи
docker-compose logs

# Проверьте, что порты свободны
sudo netstat -tulpn | grep -E '3000|8000'
```

### Не могу подключиться по SSH
- Проверьте, что файрвол разрешает порт 22
- Убедитесь, что используете правильный IP и пароль

### Frontend не подключается к Backend
- Проверьте `VITE_API_URL` в `.env`
- Убедитесь, что оба контейнера запущены: `docker-compose ps`

### Не хватает места на диске
```bash
# Проверьте использование
df -h

# Очистите неиспользуемые Docker образы
docker system prune -a
```
