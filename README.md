# BeatStore

Современная веб-платформа для продажи и распространения музыкальных битов (инструменталов) с удобным интерфейсом и системой управления контентом.

## 🎵 Описание проекта

**BeatStore** - это полнофункциональная платформа для музыкантов и продюсеров, разработанная как дипломный проект по практике. Платформа позволяет:

### Для пользователей:
- **Просмотр каталога** - просматривать и прослушивать демо-версии битов
- **Фильтрация и поиск** - находить биты по жанру, BPM, тональности, цене
- **Избранное** - сохранять понравившиеся треки для быстрого доступа
- **Корзина покупок** - добавлять биты для последующей покупки
- **Покупка битов** - приобретать полные версии инструменталов (бесплатные и платные)
- **Скачивание** - загружать купленные биты в высоком качестве
- **Аутентификация** - регистрация и вход в систему

### Для администраторов:
- **Панель управления** - веб-интерфейс для управления контентом
- **Загрузка битов** - добавление новых треков с обложками и метаданными
- **Аналитика** - просмотр статистики продаж, пользователей и активности
- **Управление покупками** - мониторинг всех транзакций в системе

## 🛠 Технологический стек

### Frontend (React SPA)
- **React 18** - современная библиотека для создания пользовательских интерфейсов
- **Vite** - быстрый инструмент сборки и разработки
- **React Router v6** - маршрутизация в одностраничном приложении
- **Context API** - управление глобальным состоянием (аутентификация, аудио плеер, уведомления)
- **React Hooks** - useState, useEffect, useRef для управления состоянием компонентов
- **Tailwind CSS** - utility-first CSS фреймворк для быстрой стилизации
- **Lucide React** - современные SVG иконки
- **Axios** - HTTP клиент для API запросов с интерцепторами

### Backend (FastAPI)
- **FastAPI** - современный, быстрый веб-фреймворк для создания API
- **SQLAlchemy** - ORM для работы с базой данных
- **SQLite** - легковесная реляционная база данных
- **JWT (JSON Web Tokens)** - аутентификация и авторизация
- **bcrypt** - безопасное хеширование паролей
- **Uvicorn** - ASGI сервер для запуска приложения
- **Pydantic** - валидация данных и сериализация

### DevOps & Инфраструктура
- **Docker** - контейнеризация приложения
- **Docker Compose** - оркестрация контейнеров
- **CORS** - настройка кросс-доменных запросов
- **Static Files** - обслуживание аудио файлов и обложек

## 📊 База данных

### Схема базы данных (SQLite)
```sql
-- Пользователи системы
users (id, username, email, password_hash, created_at)

-- Музыкальные биты
beats (id, title, artist, genre, bpm, key, price, description, 
       demo_url, full_url, cover_url, created_at)

-- История покупок
purchases (id, user_id, beat_id, price_paid, created_at)

-- Избранные треки (many-to-many)
favorites (id, user_id, beat_id, created_at)

-- Корзина покупок (many-to-many)
cart (id, user_id, beat_id, created_at)

-- Администраторы
admins (id, username, password_hash, created_at)
```

### Связи между таблицами
- **User ↔ Beat** (many-to-many через purchases) - история покупок
- **User ↔ Beat** (many-to-many через favorites) - избранные треки
- **User ↔ Beat** (many-to-many через cart) - корзина покупок
- **Admin** - отдельная таблица для администраторов

### Особенности реализации
- **JWT токены** - для аутентификации без хранения сессий в БД
- **Хеширование паролей** - bcrypt для безопасного хранения
- **Каскадное удаление** - автоматическая очистка связанных записей
- **Индексы** - оптимизация запросов по часто используемым полям

## 🔐 Безопасность

### Аутентификация и авторизация
- **JWT токены** - безопасная аутентификация без хранения сессий
- **Хеширование паролей** - bcrypt с солью для защиты паролей
- **Разделение ролей** - отдельная аутентификация для пользователей и администраторов
- **Автоматическое истечение токенов** - защита от долгосрочных атак

### Защита данных
- **CORS настройки** - контроль кросс-доменных запросов
- **Валидация данных** - Pydantic модели для проверки входных данных
- **Защита от SQL инъекций** - использование ORM SQLAlchemy
- **Санитизация входных данных** - очистка пользовательского ввода

### Сетевая безопасность
- **HTTPS** - шифрование трафика (в продакшене)
- **Заголовки безопасности** - защита от XSS, CSRF атак
- **Rate limiting** - ограничение частоты запросов
- **Валидация файлов** - проверка типов и размеров загружаемых файлов
