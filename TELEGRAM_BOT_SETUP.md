## 🚀 Быстрая настройка

### Шаг 1: Создание бота в Telegram

1. Откройте Telegram и найдите [@BotFather](https://t.me/BotFather)
2. Отправьте команду `/newbot`
3. Введите имя бота (например: `XWinner Beats Store`)
4. Введите username бота (например: `XWinnerbeatpleasebot`)
5. **Скопируйте токен** - он выглядит как `123456789:ABCdefGHIjklMNOpqrsTUVwxyz`

### Шаг 2: Добавление токена в проект

Отредактируйте файл `.env` на сервере:

```bash
nano .env
```

Добавьте или измените следующие строки:

```env
TELEGRAM_BOT_TOKEN=ваш-токен-от-BotFather
TELEGRAM_BOT_USERNAME=ваш-username-бота
MINI_APP_URL=https://ваш-домен.ru
```

**Важно:** 
- `TELEGRAM_BOT_TOKEN` - обязательный параметр (без него бот не запустится)
- `TELEGRAM_BOT_USERNAME` - опционально (по умолчанию используется из кода)
- `MINI_APP_URL` - нужен для кнопки "Открыть магазин" (можно настроить позже)

### Шаг 3: Перезапуск backend

После добавления токена перезапустите backend контейнер:

```bash
docker-compose restart backend
```

Или перезапустите весь проект:

```bash
docker-compose down
docker-compose up -d
```

### Шаг 4: Проверка работы бота

1. Найдите вашего бота в Telegram (по username)
2. Отправьте команду `/start`
3. Бот должен ответить приветствием и показать кнопку "Открыть магазин"

**Проверка логов:**
```bash
docker-compose logs backend | grep -i telegram
```

Вы должны увидеть:
```
🤖 Telegram бот запущен
📱 Username: @ваш-username
✅ Telegram бот запущен в фоновом потоке
```

## 🔗 Настройка Mini App (кнопка "Открыть магазин")

После того как у вас будет настроен домен и SSL сертификат:

### Вариант 1: Через BotFather (рекомендуется)

1. Откройте [@BotFather](https://t.me/BotFather)
2. Отправьте команду `/setmenubutton`
3. Выберите вашего бота
4. Отправьте URL вашего сайта: `https://ваш-домен.ru`
5. Обновите `MINI_APP_URL` в `.env` файле
6. Перезапустите backend

### Вариант 2: Через переменную окружения

Просто укажите URL в `.env`:

```env
MINI_APP_URL=https://ваш-домен.ru
FRONTEND_URL=https://ваш-домен.ru
```

После перезапуска кнопка будет работать автоматически.

## ⚠️ Решение проблем

### Бот не отвечает

1. **Проверьте токен:**
   ```bash
   docker-compose exec backend env | grep TELEGRAM_BOT_TOKEN
   ```
   Токен должен быть виден и не пустой.

2. **Проверьте логи:**
   ```bash
   docker-compose logs backend | tail -50
   ```
   Ищите ошибки связанные с Telegram.

3. **Проверьте интернет-соединение:**
   Бот должен иметь доступ к `api.telegram.org`

### Ошибка "409 Conflict"

Если видите ошибку `409 Conflict` в логах - это нормально! Это означает, что бот уже получает обновления в другом месте (например, на вашем локальном компьютере). Просто остановите все другие экземпляры бота.

### Бот не запускается

1. Убедитесь, что `TELEGRAM_BOT_TOKEN` установлен в `.env`
2. Проверьте формат токена (должен быть вида `числа:буквы`)
3. Перезапустите контейнер: `docker-compose restart backend`

### Кнопка "Открыть магазин" не работает

1. Убедитесь, что `MINI_APP_URL` установлен в `.env`
2. URL должен начинаться с `https://` (не `http://`)
3. Домен должен быть настроен через BotFather (`/setmenubutton`)
4. Перезапустите backend после изменений

## 📊 Мониторинг бота

Бот логирует все действия в консоль. Для мониторинга:


Бот автоматически перезапускается при перезапуске контейнера благодаря `restart: unless-stopped` в `docker-compose.yml`.

3. **Регулярно проверяйте логи** на подозрительную активность
4. **Ограничьте доступ к серверу** только необходимым IP-адресам

## 💡 Дополнительные возможности

### Расширение функционала бота

Бот находится в файле `backend/telegram_bot.py`. Вы можете:

- Добавить новые команды
- Реализовать уведомления о покупках
- Добавить поиск битов через бота
- Интегрировать с системой заказов

### Использование webhook вместо polling

Текущая реализация использует polling (getUpdates). Для больших нагрузок можно перейти на webhook:

1. Настройте HTTPS на сервере
2. Используйте библиотеку `python-telegram-bot` с webhook
3. Настройте endpoint в FastAPI для получения обновлений
