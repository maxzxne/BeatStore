# Тестовые файлы

Поместите сюда файлы для автоматического заполнения тестовыми данными:

## Структура файлов:

### Для битов (MP3):
- `demo_*.mp3` - демо-версии битов (обязательно)
- `full_*.mp3` - полные версии битов (опционально)
- `cover_*.jpg/png/webp` - обложки битов (опционально)

### Для курсов (видео):
- `preview_*.mp4` - превью видео курсов (обязательно)
- `full_*.mp4` - полные видео курсов (опционально)

## Примеры имен файлов:
- `demo_beat1.mp3`
- `full_beat1.mp3`
- `cover_beat1.jpg`
- `preview_course1.mp4`
- `full_course1.mp4`

Скрипт автоматически определит тип файла по расширению и имени.
